# idletest

Test idle request timeouts in Kubernetes.

This is a small FastAPI application that waits for a requested number of
seconds before returning a JSON response.

## Endpoint

```text
GET /idle={seconds}
```

`seconds` must be an integer from `0` through `600`.

Examples:

```bash
curl http://localhost:8080/idle=0
curl http://localhost:8080/idle=5
```

Successful response:

```json
{"message":"Waited for 5 seconds"}
```

Invalid values return `400`:

```bash
curl -i http://localhost:8080/idle=-1
curl -i http://localhost:8080/idle=601
```

## Gateway Configuration

When the app runs behind an ingress gateway, set `INGRESS_GATEWAY_HOST` to the
external gateway server name. If the gateway exposes the app under a path prefix
and strips that prefix before proxying to the pod, set `INGRESS_GATEWAY_PATH`
to that external prefix.

Both variables are required. If either one is missing or blank, the application
fails to start. Use `INGRESS_GATEWAY_PATH=/` when the app is exposed at the
gateway root.

| Variable | Required | Example | Description |
| --- | --- | --- | --- |
| `INGRESS_GATEWAY_HOST` | Yes | `myapp.local` | External gateway host used in redirect `Location` headers. It may include a scheme, such as `https://myapp.local`. |
| `INGRESS_GATEWAY_PATH` | Yes | `/idletest` | External gateway path prefix. Use `/` when the app is exposed at the gateway root. |

Missing variables cause startup errors similar to:

```text
INGRESS_GATEWAY_HOST environment variable must be defined
INGRESS_GATEWAY_PATH environment variable must be defined
```

## Gateway-Aware Redirects

Any redirect generated by the app or framework will use that host and path in
the `Location` header instead of the internal pod/service host.

The app still receives requests on its internal route. For example:

| External gateway request | Request forwarded to the app |
| --- | --- |
| `https://myapp.local/idletest/idle=5` | `/idle=5` |

Examples:

```bash
INGRESS_GATEWAY_HOST=myapp.local INGRESS_GATEWAY_PATH=/ python -m uvicorn idletest_app:app --host 0.0.0.0 --port 8080
INGRESS_GATEWAY_HOST=https://myapp.local INGRESS_GATEWAY_PATH=/ python -m uvicorn idletest_app:app --host 0.0.0.0 --port 8080
INGRESS_GATEWAY_HOST=myapp.local INGRESS_GATEWAY_PATH=/idletest python -m uvicorn idletest_app:app --host 0.0.0.0 --port 8080
```

If the value does not include a scheme, the app preserves the request scheme,
or uses `X-Forwarded-Proto` when the gateway sends it.

For example, when the external URL is `https://myapp.local/idletest/idle=5`
and the gateway forwards the request to the pod as `/idle=5`, redirect
responses from the pod will point back to `https://myapp.local/idletest/...`.

## Run Locally

Install dependencies and start the application on port `8080`:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
INGRESS_GATEWAY_HOST=localhost:8080 INGRESS_GATEWAY_PATH=/ python -m uvicorn idletest_app:app --host 0.0.0.0 --port 8080
```

Then hit the app:

```bash
curl http://localhost:8080/idle=3
```

## Run With a Container

Build and run the image:

```bash
docker build -f Containerfile -t idletest:local .
docker run --rm -p 8080:8080 \
  -e INGRESS_GATEWAY_HOST=localhost:8080 \
  -e INGRESS_GATEWAY_PATH=/ \
  idletest:local
```

Then hit the app:

```bash
curl http://localhost:8080/idle=3
```

If you use Podman, the same commands work with `podman` instead of `docker`.

## Run in Kubernetes

Apply the deployment and service:

```bash
kubectl apply -f idletest-app.yaml
```

The deployment sets `INGRESS_GATEWAY_HOST` to `myapp.local` and
`INGRESS_GATEWAY_PATH` to `/idletest`. Change those values to match the
host and path configured on your ingress gateway.

To hit the service without using ingress, port-forward the service:

```bash
kubectl port-forward svc/idletest 8080:8080
curl http://localhost:8080/idle=3
```

To hit the app through your ingress gateway, make sure `myapp.local` resolves
to your gateway address, then run:

```bash
curl http://myapp.local/idletest/idle=3
```

Or call the gateway address directly with the host header:

```bash
curl -H "Host: myapp.local" http://<GATEWAY_IP>/idletest/idle=3
```

Configure your gateway timeout settings as needed. For example, if the gateway
idle timeout is `10` seconds, `/idle=5` should complete while `/idle=11` is
useful for testing timeout behavior through the gateway.
